# Open source licenses

Hanzo Dev includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → About**, find **Open source licenses** under **Legal**,
  and select **View licenses**.
- On mobile, open **Settings → About Hanzo Dev → Open source licenses**.

The page lists the version when available, license identifier, and the parts of Hanzo Dev that include
or use the item. This also covers optional device tools that Hanzo Dev installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
